# Mycelium

A static UK mushroom scouting PWA, defaulting to Guildford, Surrey. Deploy `dist/` at an HTTPS origin root, or serve it locally. No dependencies, secrets or app backend are required. `npm run build` checks deployable files and runs the regression tests; `npm test` runs tests separately.

The daily report combines Open-Meteo modelled weather and soil moisture with iNaturalist research-grade fungi and slime mould records within 30 km. Today’s rain uses elapsed completed hours, never the whole-day forecast. Current soil water content is shown at 3–9 cm and 9–27 cm, with a three-day topsoil trend. Overnight temperature uses London local 18:00–08:00; a partial night is labelled. Seven-day rain includes today, and a 28-day background, humidity, wind and reference evapotranspiration are available in the expanded summary. These are grid estimates, not instruments in a particular wood.

A transparent 0–100 conditions index summarises scouting weather. It is an exploratory heuristic, not a percentage chance, a calibrated prediction, or a species-specific fruiting model. The in-app method describes all weights, cutoffs and missing-data handling. Missing required weather inputs produce no score. Daily habitat advice changes for frost or drying, and distinguishes the woodland floor, decaying wood, and tree roots. Suitable host trees and substrate remain essential.

The catalogue has 110 fungi habitat-guide entries plus eight slime mould entries, including dyer’s polypore/mazegill and beech/slimy milkcap. It is supplemented by unfamiliar species returned in nearby records, rather than restricted to a fixed shortlist. Recent records (14 calendar days including today) are separate from historical records for the current month across all years. Recent records rank first, then historical records, then guide candidates. Each query retrieves up to six pages of 500 taxa, with truncation disclosed. Several lichen classes and obvious microscopic plant-disease genera are excluded through an approximate taxonomic filter. Unknown habitat is labelled rather than invented. Species-level counts are not abundance or finding probabilities; no record does not prove absence.

Source-linked additions and original detailed entries reference individually checked First Nature pages. Other broad guide notes have not been independently expert-validated. Scientific-name synonyms are reconciled. Reference photographs come from matching iNaturalist taxa, with attribution and original-photo links in details. Photos do not establish identity or edibility. Never eat a specimen based on this app.

The service worker caches the shell and viewed photos; local storage keeps one latest report and photo metadata. Each data source preserves its fetch time after failed refreshes. Weather older than six hours is flagged stale. Chosen coordinates go to Open-Meteo and iNaturalist; no analytics or app account. Clear site storage to remove saved data. Private Vercel authentication can affect cold offline starts. Install on Android through the browser menu, or on iPhone through Safari Share → Add to Home Screen.

Regression tests cover today/future-hour boundaries, London dates, missing data, frost/drying advice, catalogue coverage, common-name searches, local pagination, synonyms and lichen filtering. Browser verification used the deployed static files supplied by a local test harness with live public API requests: weather, records, photos, filters, mobile layout and retention of saved data passed. This harness does not establish real service-worker offline launching; the worker and manifest are build-validated and should also be tested on an installed device.

Slime mould support queries iNaturalist Fungi (47170) and Mycetozoa (47685) together, covering Ceratiomyxa as well as myxomycetes. Separate group filtering and card labels distinguish them from fungi. Species and genus-level slime records are retained, with genus identifications kept explicit. NatureSpot source links accompany eight guide entries (seven species plus the wolf’s milk genus group); unknown seasonal ranges are not invented. Current recording names are reconciled for Hemitrichia decipiens/Trichia decipiens and Didymium spongiosum/Mucilago crustacea. The broad conditions index is not a slime mould prediction.
